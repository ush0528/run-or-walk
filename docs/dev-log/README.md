# 개발 기록 (docs/dev-log 브랜치)

## 작성 규칙

| 규칙 | 내용 |
|---|---|
| 문서 단위 | 개발 단계(주제) 하나 = 문서 하나 (`NN_주제.md`) |
| 푸시 단위 | **개발 한 번(한 단계)이 끝나면 정리해서 커밋 1개로 푸시**. 작업 중에 조금씩 여러 번 푸시하지 않음 |
| 보완 | 이미 쓴 문서를 고칠 때도 여러 수정을 모아 커밋 1개로 |
| 커밋 메시지 | `개발 기록 NN: 주제` (보완은 `개발 기록 NN 보완: 내용`) |
| 목차 | 새 문서를 추가하는 커밋에서 이 표도 함께 갱신 |
| 문서 구성 | 목적 → 절차(명령어 포함) → 시행착오(증상·원인·해결) → 발표 포인트 |
| 보안 | 인증키, 토큰, client_secret 등 비밀 값은 절대 쓰지 않음. 푸시 전에 검사 |
| 코드 | 코드 자체는 `main` 브랜치에. 이 브랜치는 기록만 |
